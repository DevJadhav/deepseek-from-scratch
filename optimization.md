#### Q2: How do we implement DeepSeek Sparse Attention (DSA) effectively in MLX?

**Algorithm Architect Response:**

```
DSA combines sliding window + dilated global attention for O(kL) complexity.

CURRENT STATE: src/deepseek/mlx/sparse_attention.py exists but needs ANE optimization

DSA PATTERN (from V3.2 architecture):

┌─────────────────────────────────────────────────────────────────┐
│  Position: 0    1    2    3    4    5    6    7    ...    L-1  │
├─────────────────────────────────────────────────────────────────┤
│  Sliding Window (w=4096):                                       │
│  Token i attends to [max(0, i-w), i]                           │
│                                                                 │
│  Dilated Global (stride=64):                                   │
│  Token i attends to {0, 64, 128, 192, ...} ∩ [0, i]           │
│                                                                 │
│  Combined Pattern (for position 8192):                          │
│  Local: [4096, 8192] + Global: {0, 64, 128, ..., 8128}         │
│  Total attention: 4096 + 128 = 4224 positions (vs 8192 full)  │
└─────────────────────────────────────────────────────────────────┘

MLX OPTIMIZATION STRATEGY:

def sparse_attention_mlx(q, k, v, window_size=4096, global_stride=64):
    B, H, L, D = q.shape

    # 1. Compute local sliding window attention (efficient on ANE)
    local_attn = mx.zeros((B, H, L, D))
    for i in range(0, L, window_size):
        chunk_q = q[:, :, i:i+window_size]
        chunk_k = k[:, :, max(0, i-window_size):i+window_size]
        chunk_v = v[:, :, max(0, i-window_size):i+window_size]
        local_attn[:, :, i:i+window_size] = scaled_dot_product(chunk_q, chunk_k, chunk_v)

    # 2. Compute dilated global attention (sparse gather)
    global_indices = mx.arange(0, L, global_stride)
    global_k = mx.take(k, global_indices, axis=2)
    global_v = mx.take(v, global_indices, axis=2)
    global_attn = scaled_dot_product(q, global_k, global_v)

    # 3. Combine with learned blend weights
    return α * local_attn + (1 - α) * global_attn
```

#### Q1: How do we implement custom Gradient Bucketing in Rust and PyTorch?

**Optimization Engineer Response:**

```
GRADIENT BUCKETING STRATEGY (from blog):

"It's like packing items into boxes before shipping... we pack gradients
into buckets before all_reduce to minimize communication overhead."

PYTORCH IMPLEMENTATION (hook-based):

class GradientBucketer:
    def __init__(self, model: nn.Module, bucket_size_mb: float = 25.0):
        self.bucket_size = int(bucket_size_mb * 1024 * 1024 / 4)  # float32
        self.buckets: List[List[torch.Tensor]] = []
        self.current_bucket: List[torch.Tensor] = []
        self.current_size = 0

        # Register backward hooks
        for param in model.parameters():
            if param.requires_grad:
                param.register_post_accumulate_grad_hook(self._bucket_hook)

    def _bucket_hook(self, param: torch.Tensor):
        grad = param.grad
        grad_size = grad.numel()

        if self.current_size + grad_size > self.bucket_size:
            # Flush current bucket
            self._flush_bucket()

        self.current_bucket.append(grad)
        self.current_size += grad_size

    def _flush_bucket(self):
        if not self.current_bucket:
            return

        # Flatten and all_reduce
        flat = torch.cat([g.view(-1) for g in self.current_bucket])
        dist.all_reduce(flat, op=dist.ReduceOp.SUM)

        # Unflatten back
        offset = 0
        for grad in self.current_bucket:
            numel = grad.numel()
            grad.copy_(flat[offset:offset+numel].view_as(grad))
            offset += numel

        self.buckets.append(self.current_bucket)
        self.current_bucket = []
        self.current_size = 0

RUST IMPLEMENTATION (manual buffer management):

pub struct GradientBucketer {
    bucket_size: usize,
    fusion_buffer: Vec<f32>,
    pending_grads: Vec<TensorView>,
    nccl_comm: NcclComm,
}

impl GradientBucketer {
    pub fn add_gradient(&mut self, grad: &Tensor) {
        if self.fusion_buffer.len() + grad.numel() > self.bucket_size {
            self.flush();
        }

        // Copy to fusion buffer (contiguous memory)
        self.fusion_buffer.extend(grad.as_slice());
        self.pending_grads.push(grad.view());
    }

    pub fn flush(&mut self) {
        if self.fusion_buffer.is_empty() {
            return;
        }

        // Single NCCL all_reduce on fused buffer
        unsafe {
            ncclAllReduce(
                self.fusion_buffer.as_ptr(),
                self.fusion_buffer.as_mut_ptr(),
                self.fusion_buffer.len(),
                ncclFloat32,
                ncclSum,
                self.nccl_comm.handle(),
                cudaStreamDefault,
            );
        }

        // Scatter back to original tensors
        self.scatter_to_grads();
        self.fusion_buffer.clear();
        self.pending_grads.clear();
    }
}

OPTIMAL BUCKET SIZE:
- Too small: High kernel launch overhead
- Too large: Delays communication start
- Sweet spot: 25MB (matches NCCL ring buffer, per blog recommendation)
```

#### Q2: How do we manage memory fragmentation and GC triggers?

**Optimization Engineer Response:**

```
MEMORY FRAGMENTATION MANAGEMENT (from blog):

"Activation memory grows quadratically with sequence length due to attention"
M_act = L · seq · bs · h · (34 + 5 · n_heads · seq / h)

STRATEGY 1: EXPLICIT GC SCHEDULING

import gc
import torch

class MemoryManager:
    def __init__(self, gc_interval: int = 100, memory_threshold: float = 0.9):
        self.gc_interval = gc_interval
        self.memory_threshold = memory_threshold
        self.step_count = 0

    def step(self):
        self.step_count += 1

        # Periodic GC
        if self.step_count % self.gc_interval == 0:
            self._aggressive_gc()

        # Threshold-based GC
        if self._memory_usage() > self.memory_threshold:
            self._aggressive_gc()

    def _aggressive_gc(self):
        gc.collect()
        torch.cuda.empty_cache()
        torch.cuda.synchronize()  # Ensure all async ops complete

    def _memory_usage(self) -> float:
        allocated = torch.cuda.memory_allocated()
        reserved = torch.cuda.memory_reserved()
        return allocated / reserved if reserved > 0 else 0

STRATEGY 2: MEMORY POOL PRE-ALLOCATION

# Pre-allocate activation memory to prevent fragmentation
class ActivationPool:
    def __init__(self, max_seq_len: int, batch_size: int, hidden_dim: int, num_layers: int):
        # Calculate maximum activation size
        act_size = num_layers * max_seq_len * batch_size * hidden_dim

        # Pre-allocate contiguous buffer
        self.buffer = torch.empty(act_size, dtype=torch.bfloat16, device="cuda")
        self.offset = 0

    def allocate(self, shape: Tuple[int, ...]) -> torch.Tensor:
        numel = math.prod(shape)
        tensor = self.buffer[self.offset:self.offset + numel].view(shape)
        self.offset += numel
        return tensor

    def reset(self):
        self.offset = 0

STRATEGY 3: GRADIENT CHECKPOINTING (blog recommendation)

"Reduces activation memory by storing only intermediate checkpoints
and recomputing missing activations during backward pass."
"Trade-off: increases computation by 30-40% but saves 70% memory"

# Apply to every N layers
def checkpoint_sequential(layers, x, checkpoint_every=2):
    for i, layer in enumerate(layers):
        if i % checkpoint_every == 0:
            x = torch.utils.checkpoint.checkpoint(layer, x, use_reentrant=False)
        else:
            x = layer(x)
    return x
```

```
OVERLAP STRATEGY (from blog):
"The computation of the next layer's gradient is independent of
the communication of the previous layer's gradient."

async fn train_step_with_overlap(model, batch, bucketer, comm) {
    // Forward pass
    let activations = model.forward(batch);

    // Backward pass with overlapped communication
    let (grad_tx, grad_rx) = tokio::sync::mpsc::channel(32);

    // Communication task (runs concurrently)
    let comm_task = tokio::spawn(async move {
        while let Some(grad_bucket) = grad_rx.recv().await {
            comm.all_reduce(&mut grad_bucket, ReduceOp::Sum).await;
        }
    });

    // Backward computation (sends gradients as available)
    for layer in model.layers.iter().rev() {
        let grad = layer.backward(&activations);
        bucketer.add_gradient(grad);

        if bucketer.should_flush() {
            let bucket = bucketer.take_bucket();
            grad_tx.send(bucket).await;
        }
    }

    // Wait for all communication to complete
    comm_task.await;
}
```
